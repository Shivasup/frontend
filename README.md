# 🚀 SkillBridge Frontend

A modern and responsive frontend application for the **SkillBridge Attendance & Management System**.

---

* 🔗 **Frontend (Live):** https://frontend-o184dpwns-shivashankarr9035-5151s-projects.vercel.app/login
* 🔗 **Backend API:** https://skillbridge-dzb1.onrender.com

---

## 📌 Project Overview

SkillBridge is a role-based web application designed to manage attendance and user operations efficiently.

### 👥 Supported Roles

* 👨‍🎓 Student
* 👨‍🏫 Trainer
* 🏫 Institution
* 📊 Programme Manager
* 🔍 Monitoring Officer

Each role has its own dashboard and permissions.
